Yes, completely free. It's open source under GPL-3.0. You only pay for the API usage from your chosen provider (e.g. Gemini, OpenAI), which is typically pennies per session.
For cloud providers (Gemini, Claude, OpenAI etc.) just download and add your API key. For local mode, you'll also need Ollama and Whisper installed — both are free and easy to set up.
Gemini offers a generous free tier. OpenAI and Anthropic give free API credits to new accounts. You can also run Ollama locally for free with no API key at all.
Only if you use a cloud provider. In local mode with Ollama + Whisper, all processing happens on your machine. Nothing is sent anywhere.
Speaker diarization works well for 2-6 speakers in a conversation. It automatically labels them (Speaker A, Speaker B, etc.) so the AI has full context of who is asking what.
Assistance runs entirely on your device and is invisible — there's no camera or screen-sharing from any external service. How you use it is your responsibility.
